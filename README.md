MIMEco paper code
=======================================================

This repository contains the scripts and resources that were used to realize the analysis described in the "MIMEco: Multi-objective metabolic modeling to predict and explain pairwise interactions" paper in msystem:

The MIMEco package repository is available `here <https://github.com/Anna-cell/mimeco>`_
And it documentation at `readthedocs : mimeco <https://github.com/Anna-cell/mimeco>`_
